# Генератор сертификатов пачкой с проверкой по номеру

Инструмент для школы: вставили список участников — получили сертификаты
комплектом, лист для печати и реестр, по которому сертификат проверяется по
номеру.

Седьмая и последняя из семи новых работ для портфолио профиля FL.ru
`kusaka63`.

## Как проверить и пересобрать

Нужны только Node 24 и системный Python macOS — ни npm, ни установки пакетов.

Тесты:

    node --test tests/*.test.mjs

Посмотреть у себя:

    /usr/bin/python3 -m http.server 8765

генератор — http://localhost:8765/, проверка — http://localhost:8765/p/.
Генератор работает и открытым с диска двойным щелчком; страница проверки —
только по адресу: ей нужен соседний файл реестра.

Пересобрать реестр примера после правки списка-примера в index.html:

    node tools/primer-reestra.mjs

Заново подрезать и вшить шрифты:

    /usr/bin/python3 tools/shrift.py

## Как устроено

Код живёт прямо в страницах, в блоках `<script id="…">`. `obshchee` —
номер и поиск в реестре, одинаковый в обеих страницах (тест следит).
`yadro` — разбор списка, кегль, шаблон, архив, реестр. Тесты выполняют
эти блоки из HTML — второго экземпляра кода нет.

Шаблон сертификата — данные в миллиметрах (`SHABLON` в блоке `yadro`).
Поменять школу, курсы или поле — правка шаблона, а не рисования.

## Чем отличается от работы на другом профиле

На `serhio2490` есть генератор меню для экрана на кассе: одна картинка 4К под
экран. Здесь пачка документов под бумагу — комплект файлов на список
участников, лист для печати A4 и проверка по номеру.

## Четыре решения

Пачка, а не один файл: двадцать сертификатов делаются за время одного. Бумага,
а не экран: миллиметры, 300 точек на дюйм и поля, за которые принтер не
заходит. Длинные имена не ломают вёрстку — кегль подбирается, двойные фамилии
переносятся. Сертификат можно проверить по номеру.

## Две границы

**Номер не защищает от подделки.** Он даёт способ проверить сертификат, не
обращаясь к его владельцу. Обещать защиту было бы обманом.

**Реестр не содержит имён.** Он лежит в открытом доступе, и список фамилий в
нём — публикация персональных данных. Проверяющему достаточно знать, что номер
настоящий: имя он видит на сертификате в руках.

## Чего не делаем и почему

Своего PDF не пишем — браузер печатает в PDF надёжнее. QR-кода нет: он
потребовал бы сторонней библиотеки против обещания «ни одной зависимости» либо
своего кодировщика с исправлением ошибок, а это не про сертификаты. Пачка
ограничена пятьюдесятью участниками: предел честнее повисшего браузера.
